Como pegar seu Token no GitHub (1 Minuto)

Para que este painel consiga criar as pastas (/tiktok, /instagram) sozinho dentro do seu GitHub sem você precisar mexer em código, o GitHub pede uma chave de permissão chamada Personal Access Token.

  1. Acesse sua conta no GitHub e vá direto neste link oficial: Criar Novo Token (Classic).
  2. No campo Note, digite: Painel PrettyLinks.
  3. Em Expiration, escolha No expiration (Para nunca vencer).
  4. Logo abaixo, marque a primeira caixinha chamada repo (Full control of private repositories).
  5. Role até o fim da página e clique no botão verde Generate token.
  6. Copie o código gerado que começa com ghp_... e cole no campo Token de Acesso aqui do painel!
💡 Dica de Ouro: Você só precisa fazer isso uma única vez! O painel salva esse Token no seu navegador para que você crie quantos links quiser em 1 clique.
